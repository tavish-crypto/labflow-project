# LabFlow

Laboratory Operations Intelligence Platform.

LabFlow is a full-stack platform designed to help diagnostic laboratory teams
track sample workflows, monitor turnaround time, detect SLA risks, manage
exceptions, and understand operational bottlenecks.

## Tech Stack

### Frontend
- React
- TypeScript
- Vite

### Backend
- Node.js
- Express
- TypeScript

### Database
- PostgreSQL
- Prisma
